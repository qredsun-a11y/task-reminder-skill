# Task Reminder Skill - 任务提醒系统

## 📋 项目概述

一个基于 OpenClaw 的任务管理和定时提醒系统，帮助用户跟踪每日任务完成进度。

## ✨ 核心功能

1. **任务收集** - 通过关键词触发自动解析任务列表
2. **定时提醒** - 每小时提醒用户确认未完成任务进度
3. **状态管理** - 完成任务、延期任务、自动续接
4. **智能交互** - 自然语言识别、上下文感知
5. **自动续接** - 第二天自动加载延期任务

## 🚀 快速开始

### 1. 安装

将 `task_reminder` 目录复制到 OpenClaw skills 目录：
```bash
cp -r task_reminder ~/.openclaw/skills/
```

### 2. 使用

#### 创建任务
```
用户：今晚有几个任务需要完成：1. A 2. B 3. C
系统：收到3个任务，我将每小时确认进度。
      1. • A
      2. • B
      3. • C
```

#### 标记完成
```
用户：A完成
系统：✅ 已标记完成！还剩 2 个任务。
      📋 当前未完成任务：
      1. B
      2. C
```

#### 延期任务
```
用户：B明天继续
系统：⏸️ 已标记延期。
      今天工作是否结束？
用户：结束了
系统：今天工作辛苦了，先休息吧！
      明天继续的任务：
      • B
      💤
```

## 🔄 工作流程

### 主流程
```
任务收集 → 定时提醒 → 用户响应 → 状态更新 → 完成检查
```

### 状态转换
```
空闲 → 任务收集 → 定时提醒激活 → 任务完成 → 结束
```

## 🎯 触发关键词

- 任务收集: "今晚有几个任务", "今天有几个任务", "待完成任务"
- 任务完成: "完成", "搞定了", "做完了", "ok了", "好了"
- 任务延期: "明天继续", "后天继续", "延期", "改天", "以后"
- 结束工作: "结束", "下班", "休息", "不做了"
- 继续工作: "继续", "还没结束", "接着干"

## 📊 数据格式

### tasks.json
```json
[
  {
    "description": "任务描述",
    "status": "未开始|进行中|已完成|延期",
    "delayed": false,
    "created_at": "2026-07-25T03:00:00",
    "completed_at": null
  }
]
```

### state.json
```json
{
  "reminder_active": true,
  "waiting_response": false,
  "last_reminder_time": "2026-07-25T03:00:00",
  "job_id": "task_reminder_20260725_030000"
}
```

## 🔧 技术特点

### 1. 模块化设计
- 任务管理、消息处理、定时提醒分离
- 易于扩展和维护

### 2. 状态持久化
- JSON 文件存储任务和状态
- 自动保存，防止数据丢失

### 3. 智能解析
- 支持多种任务格式
- 正则表达式匹配
- 自动清理标点符号

### 4. 上下文感知
- 根据当前状态提供合适响应
- 避免重复询问已完成任务

### 5. 自然语言
- 支持灵活的表达方式
- 关键词匹配而非精确匹配
